# To-Do List App

A simple and elegant to-do list application with a Notion-inspired design.

## Features

- **Add Tasks**: Quickly add new tasks with the input field
- **Complete Tasks**: Click on tasks or checkboxes to mark them as complete
- **Delete Tasks**: Remove tasks with the delete button (×)
- **Persistent Storage**: Tasks are saved to browser's local storage
- **Task Counter**: Shows remaining and completed tasks
- **Responsive Design**: Works on desktop and mobile devices
- **Clean UI**: Minimal, Notion-like interface

## How to Use

1. Open `index.html` in your web browser
2. Type a task in the input field
3. Click "Add Task" or press Enter
4. Click on tasks to mark them complete/incomplete
5. Click the × button to delete tasks

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage API
